# The Legend of Medusa | EdTechra Interactive Storybook

An interactive Greek mythology storybook built for the **EdTechra** educational platform, designed specifically for English language learners (CEFR Level A1–A2).

## 🌟 Features

- **Sequential Visual Storytelling**: 5 curated high-resolution scenes in widescreen 16:9 format with responsive framing and interactive zoom/lightbox.
- **A1–A2 English Narrative**: ~260 words written with short, accessible sentences and authentic mythological context.
- **Web Speech Audio Narration**: Listen to each chapter aloud with real-time sentence highlighting (`Play`, `Pause`, `Replay`).
- **Ambient Mythology Background Music**: Integrated with `Columns_in_the_Mist.mp3` with independent audio/sound controls.
- **Interactive Vocabulary Exploration**: Clickable key terms (`ancient`, `beautiful`, `curse`, `Gorgon`, `stone`, `monster`, `shield`, `reflection`, `defeated`, `legend`) with definitions, example sentences, and audio pronunciation.
- **Visual Discovery ("Explore Image")**: Guided observations for each chapter artwork turning illustrations into learning activities.
- **In-Chapter Mini Checks**: Micro-interactions with instant educational feedback.
- **Responsive & Accessible**: Touch-friendly ($44 \times 44\text{px}$ touch targets), keyboard navigable (`Arrow` keys, `Space`, `Escape`), and reduced-motion compliant.

## 🚀 How to Run

Simply open `index.html` in any modern web browser:
```bash
# Or start a local server
npx serve .
```

## 📜 Chapters Overview

1. **Chapter 01 — Before the Curse**: Medusa the Maiden in Athena's temple
2. **Chapter 02 — The Curse**: The transformation of her hair into living snakes
3. **Chapter 03 — The Hidden Monster**: Alone by the sea cliffs
4. **Chapter 04 — Perseus**: The hero approaching Medusa using the polished bronze shield reflection
5. **Chapter 05 — The End of the Legend**: The golden Gorgoneion shield of Athena and the enduring myth
